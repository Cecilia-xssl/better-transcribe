# 撰写系统 —— 写字机手写誊抄管线 + Web 控制台

> **AI 辅助开发项目**：本项目由 MiMoCode（AI 编程助手）与用户协作完成，代码经多轮实机调试打磨。
> 欢迎 Issue / PR。

把文档（Word / PDF / Excel / XMind）转成手写笔迹并驱动 GRBL 写字机誊抄到纸上：
解析排版 → 笔画渲染 → G-code → 串口发送（含急停/断点/换纸流程）。

本地网页控制台提供：预览、批量队列、模板编辑（栏位拖拽/背景识别）、机器预设、校准定位、实时日志。

## 功能

- **四类文档**：`.docx`（段落/表格/图片/形状/公式/原生图表）、`.pdf`（文本+矢量）、`.xlsx/.xlsm`（表格）、`.xmind`（思维导图）
- **排版还原**：字号/对齐/缩进/表格网格线/图文混排/多页分页
- **手绘质量**：连续曲线一笔到底、长线自动抬笔防纸面扭曲、表格唯一网格线
- **图像描摹**：统计图表线型编码、地图区域排线、SVG 矢量、素描化照片
- **填表模式**：模板栏位（文本/公式双模式）+ 批量换纸 + 断点续写
- **安全链**：轨道边界校验、碰撞看门狗、急停（`!`+`0x18`）、机器预设失焦复输确认

## 快速开始

```
pip install python-docx pyserial Pillow openpyxl pymupdf
python scripts\kenjoy_server.py
```

浏览器打开 http://127.0.0.1:8765（仅本机监听）。

首次使用：

1. 在「机器预设」填写串口号、落笔/抬笔 Z、速度等（Grbl 1.3a，本机实测 COM5/115200）
2. 在「模板」区调整纸张尺寸与栏位位置（支持导入背景图 + 自动识别下划线）
3. 放好纸张，点「定位轻点」验证落笔，再拖入文件开始誊抄

## 字库

笔画渲染优先使用 **gfont 字库**（奎享雕刻商业字库，`gcodeFonts/` 目录）。本仓库**不分发商业字库**——请自行准备 `.gfont` 文件放入 `gcodeFonts/`，或配置 `config.json` 的 `font_root` 指向外部字库目录。

**没有商业字库也能直接用**：gfont 缺失时自动降级到开源笔顺数据，按字联网拉取一次后缓存在 `hw_cache/` 离线复用，无需任何额外配置。

## 配置

- `config.json` —— 全局配置（字库目录、默认字体、outbox 路径）
- `scripts/headless/templates/scau-report-16k.json` —— 纸张/栏位/正文区模板（网页端可视化编辑，导入导出）
- 运行产物（预览图/G-code/日志/断点）在 `%USERPROFILE%\.KenjoyDraw\mimo-outbox\`

## 硬件与固件

| 项 | 要求 / 实测值 |
|---|---|
| 控制器固件 | **Grbl 1.3a**（Arduino 兼容 CNC 控制器） |
| 串口 | USB-串口（CH340 等），**115200** 波特率；端口可配（实测 COM5） |
| 驱动 | 步进电机 X/Y/Z，**Z 轴为落笔轴（+Z = 落笔方向）** |
| 限位开关 | **无**（软件边界防护 + 碰撞看门狗；建议加装） |
| 行程 | 约 210×297mm（A4 级），坐标系原点 = 纸右上角，纸体在负 X 区 |
| 笔 | 普通中性笔/滚珠笔，Z 落笔深度约 7–10mm 可调（按机器标定） |

其他 Grbl 版本/舵机抬笔（M280）留有配置位但未实测。换纸/暂停期间电机松开，回车继续（不要移动笔架）；急停后 `$X` 解锁。
